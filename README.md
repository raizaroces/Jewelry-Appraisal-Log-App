# Jewelry Appraisal Log App

A mobile inventory and appraisal management app created as an academic project for BSIT 2nd Year coursework. Built using Android Studio with local database integration (SQLite).

## Features

- **Full CRUD Operations:** Allows users to Add, Update, Delete, Search, and List jewelry appraisal entries.
- **Data Fields:** Tracks essential item properties including Item ID, Item Name, and Appraisal Value.
- **List & Search View:** Displays recorded items in a clean tabular format with dedicated Search functionality.
- **Custom Retro UI:** Features a blue pixelated retro/digital aesthetic with intuitive action buttons and navigation controls.
